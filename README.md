# fullfreq
 lemmanized frequency lists with POS, using stanza and fineweb (for now) <br>
 **very unfinished**, will be updated in the future 

## requirements
 * you need a big dataset like fineweb 2 data as jsonl for example 
 * you need stanza, json, tqdm, csv, collections, re

## setup
* make sure you have [python](https://www.python.org/) installed <br>
* run to intall:     `` pip install stanza json tqdm csv collections re `` <br>
* run to get data: `` python getData.py `` <br>
* then scan the data: `` python makeFreq.py `` <br>
